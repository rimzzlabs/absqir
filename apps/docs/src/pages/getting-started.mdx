# Install absqir

<div role="doc-subtitle">Put a working instance on a machine in about ten minutes</div>

This page puts a working instance on a machine. It takes about ten minutes.
When the instance answers, go to [Run your first event](/first-event).

If you do not know what absqir is yet, read [What absqir is](/what-is-absqir)
first.

:::note
This page installs the Docker stack on a machine you keep. To run absqir
without a server, see [Deploy to Cloudflare](/cloudflare), which uses Workers
and a hosted Postgres.
:::

## Before you start

- A machine with [Docker Engine](https://docs.docker.com/engine/install/) and Docker Compose.
- Node.js 22 or newer, on the machine you run the CLI from.
- 1 GB of free memory for the app and its Postgres.
- A [Resend](https://resend.com) API key. Sign-in codes and invitations travel
  by email, and the stack refuses to start without a key.

:::note
The free Resend tier sends from `onboarding@resend.dev` and reaches only the
address that owns the Resend account. That is enough to install and test. To
reach other people, verify a domain. See [Going to production](/production).
:::

## Create the instance

The CLI writes a compose file and a `.env` with fresh secrets. Run it in an
empty directory.

```bash
npx absqir@latest init my-absqir
cd my-absqir
```

On a terminal it asks for the address the instance answers on, the Resend API
key, the From address, and the sign-in providers. It prints the page to open
before each key it asks for. Press Enter to take the default of a question.

Set the mail key and the From address here if you left them empty:

```bash
npx absqir config set RESEND_API_KEY re_xxxxxxxx
npx absqir config set EMAIL_FROM "absqir <onboarding@resend.dev>"
```

## Start the stack

```bash
npx absqir up
```

Docker pulls two images and starts them. The app log then follows on your
terminal until the app answers, the way a normal start does. The app applies
the database migrations before it serves anything, so the first start takes
longer than the ones after it. When the app answers, `up` prints the address
to open and the one thing to do there.

If the app stops on a fault it cannot recover from, `up` prints the cause and
the fix instead. To follow the log again later:

```bash
npx absqir logs
```

Check the instance at any time:

```bash
npx absqir doctor
```

`doctor` verifies Docker, the two instance files, the length of
`BETTER_AUTH_SECRET`, the mail key, and the health endpoint. It exits non-zero
when a check fails, so it fits in a script.

## Take the first account

Open `http://localhost:4321` and enter your email address.

The first account on a fresh instance is the operator. It receives a 6 digit
code, and the code creates the account. Onboarding then asks for a name, a
password, an optional picture, and your first organization.

:::warning
The operator is whoever signs in first. On a machine other people can reach,
take the first account before you tell anyone the address.
:::

After the operator exists, a new email address needs an invitation. See
[Accounts and organizations](/accounts) for the full rule.

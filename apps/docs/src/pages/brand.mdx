# Brand

<div role="doc-subtitle">The mark, the lockup, the palette, and the type</div>

The absqir mark is the first letter of the name, set on a QR module grid. A
double-story `a`, eleven modules wide and thirteen tall, drawn with two-module
strokes. The counter of the letter holds a cobalt block, the way a QR finder
pattern holds its centre. The letter is the code. The block is the person who
checked in.

## The lockup

The mark and the name travel together. The wordmark is JetBrains Mono 600,
the same face the app uses, converted to outlines. Outlines carry no font
dependency, so the lockup is identical on every machine, in a browser tab, in
a README, and in a slide. The mark stands 48 units tall in a 64 unit lockup,
so it reaches a little past the ascender of the `b` and the descender of the
`q`, and 18 units of air sit between the two. This is the sidebar logo, the
header logo, and the image to use anywhere the name appears beside the mark.

Use the mark alone where the name is already on the screen, or where the space
is square: a favicon, an avatar, an app icon.

## Grain

The mark has two grains. The gapped grain keeps a gap between modules, so the
grid reads as a QR code. Use it at 32 px and above. The fused grain joins the
modules into one solid letter. Use it below 32 px, where a gap would blur into
grey. The favicon ships in the fused grain, white on a cobalt tile, with a
margin around the letter. The tile carries its own ground, so no browser adds
a backing behind it on a dark tab strip. Every other file ships in the gapped
grain, and the gaps close on their own as the mark gets small.

## Color

| Token  | Light     | Dark      | Usage                                                       |
| ------ | --------- | --------- | ----------------------------------------------------------- |
| Ink    | `#131A26` | `#E7ECF4` | The letter's modules, headings                              |
| Paper  | `#F6F8FB` | `#10151E` | Grounds, tinted toward cobalt — never pure white or black   |
| Cobalt | `#2563EB` | `#7CA9FF` | The block in the counter, links, focus, one accent per view |

Cobalt marks the brand, not a state. Success, warning, and error keep their
own semantic colors inside the app.

## Typography

- **Wordmark**: JetBrains Mono 600, always lowercase: `absqir`. Use the
  outlined lockup above for artwork. Set live text in the same face at the
  same weight. Never capitalize the name, in prose either.
- **Text**: Inter. Both faces already ship with the app. The brand adds no
  font.

## Usage

- Keep clear space around the mark of at least two modules.
- Do not rotate, distort, outline, or add effects to the mark.
- Do not recolor the mark outside ink and cobalt.
- Do not set the letter in a font. The mark is a bitmap, and only the files
  below draw it.
- On photos or busy grounds, place the mark on a paper-colored tile first.
- In email, use the tile. A mail client that repaints a message for dark mode
  leaves images alone, so the tile keeps the ink strokes on their own ground.

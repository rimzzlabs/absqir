# Configuration

<div role="doc-subtitle">Every setting the instance reads, and what it changes</div>

The instance reads its settings from the `.env` file next to
`docker-compose.yml`. Change a value with `absqir config set`, then apply it
with `absqir up`.

| Key                  | Default                          | What it does                                                                                                                     |
| -------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `BETTER_AUTH_SECRET` | generated by `init`              | Signs sessions and cookies. 32+ characters.                                                                                      |
| `POSTGRES_PASSWORD`  | generated by `init`              | The database password.                                                                                                           |
| `RESEND_API_KEY`     | empty, required                  | Sends sign-in codes and invitations through [Resend](https://resend.com). The app refuses to start in production without it.     |
| `EMAIL_FROM`         | `absqir <onboarding@resend.dev>` | The From address. Use a domain you verified in Resend.                                                                           |
| `PORT`               | `4321`                           | The published port on the host machine.                                                                                          |
| `SECURE_COOKIES`     | `false`                          | Marks cookies `Secure`. Set to `true` behind HTTPS. Over plain http the browser drops Secure cookies and sign-in fails silently. |
| `REGISTRATION_OPEN`  | `false`                          | Lets any email register and create organizations. Off means invitations only, plus the first account.                            |
| `APP_URL`            | `http://localhost:4321`          | Where this instance answers. Links in a reminder email point here, so set it to the address people type.                         |
| `ABSQIR_TAG`         | `latest`                         | The image tag `absqir upgrade` pulls. Pin a version for reproducible deploys.                                                    |
| `GITHUB_CLIENT_ID`   | empty                            | Turns on the GitHub button with `GITHUB_CLIENT_SECRET`. See [Sign in with GitHub and Google](/oauth).                            |
| `GITHUB_CLIENT_SECRET` | empty                          | The other half of the GitHub pair. One half alone stops the server.                                                             |
| `GOOGLE_CLIENT_ID`   | empty                            | Turns on the Google button with `GOOGLE_CLIENT_SECRET`.                                                                         |
| `GOOGLE_CLIENT_SECRET` | empty                          | The other half of the Google pair.                                                                                              |

Two more variables exist on the container itself, outside `.env`:

| Key               | Default      | What it does                                                                                     |
| ----------------- | ------------ | ------------------------------------------------------------------------------------------------ |
| `SKIP_MIGRATIONS` | `false`      | Skips the automatic migrations on start. Use with `absqir migrate` when you want manual control. |
| `ENVIRONMENT`     | `production` | Turns on HSTS, hides the API docs page, and requires `RESEND_API_KEY`.                           |
| `CRON_SECRET`     | empty        | Turns on `POST /api/tick` for a scheduler outside the app. See [the heartbeat](/notifications#the-heartbeat). Docker and Node run the same work on a timer, so a self-host can leave it empty. |

## Sign-in providers

The four OAuth keys are optional. With none of them set, the sign-in page asks
for an email and nothing else. Set a pair and a button appears. The callback
address follows `APP_URL`, so set that first.
[Sign in with GitHub and Google](/oauth) walks through both providers.

## Email in development

Outside production the mailer is optional. Without a key, the server prints
each code and each invitation link to its log:

```
[absqir mail] code for ada@example.com (sign-in): 482913
[absqir mail] invitation for grace@example.com: http://localhost:4321/invite/...
```

## API reference

Every instance serves its own interactive API reference at `/api/reference`
while `ENVIRONMENT` is not `production`, or when `ENABLE_DOCS=true` is set on
the container.
